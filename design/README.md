# rireki UI / Storybook

Rust / GPUI で実装された現在の GUI をブラウザーで確認するための Storybook です。
React / TypeScript / Vite を使い、本体と独立して起動・ビルドできます。

## 起動

Node.js 22.12 以降、npm 10 以降を使用してください。

```sh
cd design
npm ci
npm run storybook
```

http://127.0.0.1:6007 で開きます。別のポートを使う場合は
`npm run storybook -- --port 6010` を実行してください。

## 収録内容

- **画面 / タイムライン**: 全履歴、読み込み元・プロジェクトの絞り込み、料金、ディレクトリ表示、検索、サイドバーの開閉。
- **画面 / カレンダー**: 日・週・月、セッション選択。
- **画面 / 統計**: 6 指標、推移、プロジェクト・セッション順位、曜日と時間帯、モデル、ツール、読み込み元。
- **画面 / 状態**: 読み込み中、履歴なし、検索結果なし。
- **パネル / セッション詳細**: セッション、イベント、ツールの入出力・失敗、ファイルと差分、分析、全画面、進行中。
- **パネル / オーバーレイ**: 表示設定、期間・日付の選択、キー操作、MCP の停止中・実行中。
- **コンポーネント / 基本部品**: ボタン、イベントブロック、状態表示、集計、セグメント切り替え。
- **デザイントークン / テーマ**: 配色、イベントの色、角丸・文字・余白・透明度、寸法。

「操作：」で始まるストーリーは `play` 関数で操作を実行し、結果を検証します。
Controls で初期状態を変えるとコンポーネントを作り直すため、再現したい状態を安定して確認できます。

## 操作と再現範囲

読み込み元・プロジェクト・検索語による絞り込み、セッション・イベント選択、詳細タブ、
カレンダー切り替え、期間移動・拡大縮小、ブロック集約、パネルの幅変更、
履歴の再生、分析フィルター、コピー、サンプルイベントの JSON 保存を操作できます。
パネルの境界はドラッグ、またはフォーカスして左右キーで変更できます。
検索欄には `⌘K` / `Ctrl+K`、詳細タブには `1`–`4`、各表示には `D` / `W` / `M` を使えます。

データと現在時刻は **2026/10/26 の架空サンプル**に固定しています。
統計は共通サンプルから算出し、日・週・月とタイムラインで同じセッションを使います。
入力・結果、差分、使用量の内訳は UI 確認用のサンプルです。
実際の JSONL ログや本体のキャッシュは読み込みません。
MCP の開始・停止は表示状態のシミュレーションで、サーバーを起動しません。
再開コマンドのコピーにもサンプルのセッション ID を使用します。

ネイティブ GUI の既定サイズ 1500 × 920、最小サイズ 960 × 600 を基準としたデスクトップ UI です。
画面の高さはプレビューに追従します。狭い画面では Storybook の全画面表示または新しいタブで確認してください。
GPUI の描画エンジンや OS のフォントラスタライズまでは共有していません。

## デザイン原則

画面を足す・直すときの判定基準です。迷ったら「これは情報か、飾りか」で決めます。

- **色**
  - 色を使うのはデータ（イベントの種類、Claude / Codex、プロジェクト、失敗・拒否・中断）と選択状態だけです。
  - 成功は無色です。文字は文字色だけで書き、データの色は隣の印（点・線）で示します。
  - 例外は差分の追加（緑）と削除（赤）、量を表す青の 5 段（`heat`）、ロゴの地色（`brand`）です。
  - 色に透明度を掛けた塗りでバッジを作りません。
- **面**
  - 枠と角丸で囲むカードを作りません。区切りは余白か罫線 1 本です。
  - 色付きの左帯を付けません。影はポップオーバーとモーダルだけです。
- **角丸**: `radius` の 4 段（3 / 6 / パネル 10 / 内側 9）だけです。正円は点にだけ使います。
- **文字**: `fontSize` の 5 段（11 / 12 / 13 / 16 / 20px）だけです。11px は軸・時刻・件数・キー表記などの補助の文字です。太さは通常と 600 の 2 つです。
- **余白**: `space` の 4px の倍数だけです。負のマージンを使いません。グラフの棒や点の間など、1〜2px の区切りのすき間は除きます。
- **透明度**: `alpha` の 4 段（無効・古い結果・範囲の塗り・差分の行）だけです。
- **アイコン**: 文字だけでは区別できない場所に限ります。見出し、全行に同じアイコン、飾りの枠、意味の合わないアイコンは付けません。
- **文言**
  - 見れば分かる補足、脚注、2 段目の説明は書きません。
  - 画面から読めない事実だけを、該当する値のツールチップに 1 文で書きます。
  - 同じ概念は 1 語で呼びます（料金は「料金」）。同じ要素に別々の文言の `aria-label` と `title` を付けません。アイコンだけのボタンは、同じ文言を `aria-label` と `title` に一度ずつ付けます。
- **状態**: 空状態は 1 行の文字だけです。再集計中は前の結果を薄く表示し、前の結果がない初回は「読み込み中…」の 1 行だけを出します。

### イベントの色

判別できる色相は 5 つ（ユーザー・参照・編集・シェル・エージェント）に絞り、応答・思考・その他は無彩色の濃淡にしています。
Claude の橙、Codex の青緑、失敗の赤はイベントに使いません。

dataviz スキルの検証器（`validate_palette.js`、`--mode dark`、面は `panel`）の結果です。

| 条件                     | 結果                                                                                |
| ------------------------ | ----------------------------------------------------------------------------------- |
| 明度の帯・彩度の下限     | 5 色すべて通過                                                                      |
| 正常視覚の下限（隣接）   | 最小 ΔE 18.5（下限 15）                                                             |
| 正常視覚の下限（全ペア） | 最小 ΔE 17.2（下限 15）                                                             |
| 色覚特性（隣接）         | 最小 ΔE 16.4                                                                        |
| 色覚特性（全ペア）       | 最小 ΔE 6.1（警告帯）。ブロックのアイコンとラベル、凡例で補う                       |
| 面とのコントラスト       | 編集・参照・エージェントが 3:1 未満（警告）。ブロックのアイコンとラベル、凡例で補う |

7 色相では全ペアの最小 ΔE が 12.5 までしか上がらないため、色相を増やしません。
色を足すときは、検証器を全ペアで通してから `tokens.ts` と `styles.css` に追加します。

## 検証と静的ビルド

```sh
npm run typecheck
npm run format:check
npx playwright install chromium  # 初回のブラウザーテスト用
npm test
npm run build-storybook
```

`npm test` は Chromium 上で全ストーリーを描画し、操作ストーリーのアサーションを検証します。
`npm run test:watch` または Storybook 左下のテスト UI でも実行できます。
アクセシビリティアドオンは、既存の配色を保持した状態で問題を確認するためのレポートとして有効にしています。
既存 UI と同じコントラストの箇所は自動テストの失敗条件にはしていません。

静的ファイルは `design/storybook-static/` に生成されます。
`node_modules/`、ビルド成果物、テスト成果物は Git に含めません。
